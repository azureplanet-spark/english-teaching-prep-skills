# 🎓 English Teaching & Lesson Prep Skills (英語教學備課專用 AI Skills)

## 🌟 專案願景 (Vision)

本專案旨在收集、維護並開源一系列高品質的 **AI Agent 英語教學與備課 Skills**（相容 Antigravity、Claude Code、Codex 等現代 Agent 系統），協助教育工作者在幾秒鐘內產出具備**「課綱學術鷹架」**、**「分級適配」**與**「互動回饋」**的現代化英語教材。

---

## 📜 專案演進脈絡與著作權聲明 (Heritage & Lineage)

本專案之教材設計秉持開源與教育共享精神：

1. **🌱 初代發想與原型構建 (v1.0)**：由 **RaeHo (azureplanet-spark)** 最早發想並構建最初之「英語歌曲互動學習單」原型。
2. **🏫 高中職課堂深化 (v2.0)**：由 **hsinyuchi (Sylvia)** 老師基於初代原型，針對臺灣高中職課堂標準、108 課綱學習歷程檔案與 CEFR A1~A2 學生需求進行深度教學優化，並建立《Count on Me》旗艦教學母版。
3. **🚀 通用進階版模組化重構 (v3.0)**：由 **RaeHo (azureplanet-spark)** 吸收深化精華，進行全面核心拆解、參數化與模組化擴充（開放自訂教師/機構名稱、CEFR A1~B2 四級適配、三大題型切換、本機 MP3/MP4 雙播放引擎與彈性本機/雲端部署），升級為適用全年齡與多元教學情境之通用版本。

## 🚀 如何安裝與使用 (Installation)

### 方式一：直接複製至本機 Agent Skills 目錄
將本專案內的 Skill 資料夾複製至您的 Agent 設定路徑：
- **Antigravity / Gemini CLI**: `~/.gemini/config/skills/`
- **Claude Code**: `~/.claude/skills/`

### 方式二：Git Clone
```bash
git clone https://github.com/azureplanet-spark/english-teaching-prep-skills.git
```
